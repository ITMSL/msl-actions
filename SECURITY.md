# Sicherheitshinweise

Dieses Repository enthaelt geteilte CI-Mechanik (Composite-Actions und einen
wiederverwendbaren Deploy-Workflow) — keinen Anwendungscode und keine
Infrastrukturangaben. Serveradressen, Ports und Zugangsdaten sind Eingaben
der privaten Aufrufer.

## Schwachstelle melden

Bitte per Mail an it@msl-express.de — nicht als oeffentliches Issue.
Kein Bug-Bounty-Programm.

## Unterstuetzte Staende

Nur der Branch `main` wird gepflegt; Konsumenten referenzieren ihn direkt.
